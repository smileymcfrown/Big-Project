How this code was checked

Every script was compiled with a real C# 9 compiler against stubs of the Unity APIs it uses, and the API names were checked against the actual package sources (NGO 2.13.3, XRI 3.6.1, Input System 1.20.1, Multiplayer Services 2.4.0). The 15 unit tests pass. It has not been run inside the Unity editor or on a headset, so expect the odd Inspector wiring slip; the checklists are there to catch them.
